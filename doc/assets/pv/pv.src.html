make · Taskfile
Shell commands listed in a Makefile or YAML.
  • Quick to start
  • Nothing is checked until it runs
  • Every tool installed on every machine
Lask
A small typed language for tasks, running on Docker.
  • Checked before anything runs
  • Every tool runs in a pinned image
  • Install Lask + Docker, nothing else
Dagger · Earthly
CI pipelines as code, on a container build engine.
  • Containerized and reproducible
  • Caching built for large builds
  • More to learn and set up before the first task
